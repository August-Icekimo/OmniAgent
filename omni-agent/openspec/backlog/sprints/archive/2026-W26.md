### What worked
- **A2A PoC 完整落地（PR #13）**：Committed 項目 `antigravity-a2a-integration-path` 按時交付。成功建立 `agy` 隔離容器服務（read_only, tmpfs, cpu/mem/pids 限制等），並透過 `a2a-sdk` 提供 A2A Task API，與 Brain 實現 single-turn 委派與共享 volume 產物交換。
- **Circuit Breaker 降級與安全**：完成 crash-safe 429 熔斷器（circuit breaker），狀態保存於 `home_context` DB 表，開啟期間直接降級且不耗用 Gemini API quota。
- **高品質 Code Review**：PR 期間 Claude Code 提出 1 個 Medium 與數個 Minor findings（M1–M4），包含熔斷器毀損 fail-open、half-open 重搶 DB CAS 鎖、調整 redact/breaker 執行順序等，均在 merge 前修復完成。
- **外部依賴與 provider chain 修復**：
  - 更新 router.py 將退役/404 的 Claude 模型替換為 `claude-sonnet-4-6`，並修復 Gemini API 403 異常，解決 provider chain 暫時性退化。
  - **實證 planner 自動選用**：在 provider chain 恢復後，實測證實 Claude/Gemini 可在 planner_node 自動且正確地選擇呼叫 `delegate_to_specialist`（I5 標記 resolved）。
- **佇列安全性加強**：提前修復 turn 處理逾時與孤兒 turn 收割機制（commit 02b4c49），避免 A2A 異常或逾時導致 user queue 死結。

### What didn't
- **Stretch 項目未動工**：由於 PR #13 審查修正、依存 provider chain 故障修復、逾時機制重構等佔用剩餘時間，`home-assistant-skill` 與 `reporter-node-truncation-backstop` 本 sprint 未能開工。
- **去識別化（de-id）覆蓋範圍有限**：目前的 `redact_names` 僅依賴 `users.name` 字面替換，暱稱、稱謂及電話號碼等尚未涵蓋，留待後續擴充。

### 實測教訓（值得記）
1. **依賴套件鎖定陷阱**：`google-adk 2.3.0` 對 `a2a-sdk` 的 constraint 限制了與 `1.1.0` 新 server API 的相容性。在 ADK 升級前，兩端切勿擅自升級 `a2a-sdk`，必須保持 lockstep。
2. **DB schema 複用省去 migration 開銷**：利用 JSONB 欄位將 circuit breaker 狀態存入既有 `home_context` 表，既實現了 crash-safe，也免去了撰寫/手動套用新 DB migrations 的手續。
3. **模型退役（Model End-of-Life）的無聲影響**：老舊 Claude 模型 ID 退役會造成 routing fallback 及 tool choice 失效。應定期檢查 routing_config.json 中的模型狀態，避免干擾 automated tool selection 的測試。
