## Retro

> 本 retro 於 2026-10-26 補寫（窗口 09-27 結束後 29 天）。W36 的 retro 遲交 6 天，
> 這次遲交 29 天 —— 同一個失效模式，惡化中。

### What worked
- **Goal 1 刻意訂低是對的。** 「窗口內至少一個 commit」把空轉三個 sprint 的僵局打破：
  09-19 一天內 7 個 commit，三個 Goals 全數達成。低門檻目標確實能逼出第一個動作。
- **用查證關卡，而不是用意志力關卡。** `reporter-node-truncation-backstop` 不是
  「放棄」而是開工前查證兩個前提已隨 PR #10 消失，以 won't-do 有據關閉，四度延宕終結。
- **preflight 一條龍**：propose → apply → 實機驗證 → archive 同日完成，順手修掉
  ClaudeClient 的 config model 從未生效的問題。2026-10-26 brain 重建時它正確回報
  3 ok / 1 failed（local 離線），掛在 `compose up` 上的設計有效。

### What didn't
- **爆發只有一天。** 09-19 之後到窗口結束（09-27）零 commit，之後一路空到 10-26。
  「打破空轉」做到了，但沒有延續成節奏 —— 一次性衝刺不等於恢復開工習慣。
- **Cindy 六週無人察覺地失能。** 最後一筆 conversation 是 09-15；期間 Gemini API
  被 Google 強制改 prepay（約 10-12 切換）餘額 0 回 402、chrysoberyl 離線，而
  routing_rules 全導 local（離線時推論 turn 會在 fallback 前逾時）。`/health` 一直回 ok，
  沒有任何訊號提醒。**健康檢查只證明行程活著，不證明 Cindy 會回話。**
- **preflight 的盲區**：它驗 model id 存在與權限，不驗帳務／額度 —— Gemini 402 期間
  preflight 照樣報 OK。
- **Stretch `specialist-deid-scope-expansion` 未碰**，open questions 依舊。
- **retro 遲交 29 天。** `/opsx:plan` 的 retro gate 確實存在
  （`omni-agent/.claude/commands/opsx-plan.md` Step 1），但它只在有人執行 plan 時才擋；
  沒人開新 sprint，gate 就永遠不觸發，也不會提醒任何人。
